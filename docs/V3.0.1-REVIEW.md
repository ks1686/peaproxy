# v3.0.1 — review of #118

Copilot's review of #118 raised 19 findings. This records what was verified,
what was fixed, and what is still open. Nothing here is taken on trust: each
finding was checked against the code at `c3aea2a`.

## Fixed in v3.0.1

| Finding | Defect | Severity |
| --- | --- | --- |
| Unpriced days exclude calls from spend totals | `SpentInLastDays` skipped a day whose `CostUSD` was nil, skipping its call counts too. A fully unpriced day reported `priced == total == 0`, so the ceiling read it as measurably nothing spent and **failed open** — the opposite of the documented behaviour. | Critical |
| Cache keys ignore session-specific bodies | Coalescing keyed on the caller's body while the upstream request carried that session's artifacts, letting identical text from two sessions share an answer. | Critical |
| Local routing permits cloud fallback | `automaticKind` returned the general `cloudFallback` setting for `pea/local`, so a route named for on-machine execution could answer from a cloud account. | Critical |
| Duplicate content keys discard retrieved passages | The reference block emitted `content` three times in one JSON object. Duplicate keys are not a list — a decoder keeps the last, so the model received the closing delimiter and **no passages**, while the feature reported itself as working. | Critical |
| Artifact store never initialized | `Artifacts` was never assigned outside tests and every context path treats nil as skip, so carried context and `pea_search` **never ran** while the README listed them as shipped and on by default. | High |

The last one was the reason the fourth was invisible: with the store always
empty, the broken prefetch block was never exercised.

## Open — not fixed in this patch

These are recorded rather than silently dropped.

- **Spend ledger is largely unpriced.** `Event.CostUSD` is only set from a
  numeric `usage.cost`, which most providers do not send. Published token counts
  are not priced against the deployment quote, so the ceiling tracks spend only
  where a provider volunteers a cost. This undercuts the ceiling's usefulness
  and is the largest remaining gap.
- **Spend ceiling is a post-hoc threshold**, with no per-request reservation, so
  concurrent requests can all pass the same check and overshoot.
- **Exact-model routing bypasses `freeOnly` and the ceiling**; both are only
  consulted inside automatic selection.
- **`Price.Free()` ignores paid cache reads/writes**, so a deployment priced at
  zero for input/output but paid for cache is treated as guaranteed free.
- **Round limit leaks the proxy tool call** to the client instead of reporting
  exhaustion.
- **Retrieval rounds' usage is discarded**; only the final response reaches the
  ledger.
- **The assistant tool-call message is not appended** before tool results, so
  strict OpenAI-compatible servers reject the second round.
- **`openai_compat` declares tool support universally**, overstating capability
  for unknown endpoints.
- **Prompt-cache insertion does not validate the `system` element shape**, so a
  string containing a brace can be corrupted.
- **Only the Chat Completions stream flushes** the route rewriter; Responses and
  Messages do not.
- **Anonymous-provider consent is not enforced** in routing.
- **Economy ranking compares input rates only**, so a low-input/high-output
  deployment can cost more.
- **Cache warmth can override a cheaper deployment** on output rate.
- **The eval's economy scenario uses non-crossed rates**, so an
  input-only comparison would pass the gate.
- **The UI smoke's `#preset` locator no longer matches** after the Policy page
  was added, silently skipping an assertion.

## Honest summary

v3.0.0 shipped four guarantees the code did not honour: the spend ceiling could
fail open, `pea/local` could leave the machine, carried context did not run, and
retrieved passages were silently discarded. All are fixed here with regression
tests that fail against `c3aea2a`.

The remaining open items mean the spend ceiling is real but not yet a hard cap,
and several capability claims remain broader than the evidence supports.
