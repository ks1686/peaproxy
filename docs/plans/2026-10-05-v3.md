Status: local plan for review; implementation and publication not started.

Target: v3.0.0. Plan date: 2026-10-05.

## Goal

A drop-in, opinionated provider endpoint combining provider aggregation, reliable streaming, quality-constrained cost routing, free allowances, optional local inference and recoverable context optimization. Existing clients need only the provider connection and model selection; plugins are never required. Optimize cost per successfully completed task, not token reduction alone.

## Architecture

Client → wire-preserving request analysis → capability/privacy/session gates → deployment economics and quota selection → cache/context policy → bounded upstream attempts → wire-correct stream → usage ledger. Context retrieval may add bounded internal model turns, never arbitrary execution. Native opaque fields remain intact; a normalized view is advisory, not a lossy replacement for the request.

Keep the Go gateway and embedded browser UI. No mandatory Python service, Redis, paid classifier or client plugin. Use existing adapter, catalog, router, quota, usage, streamguard and config packages. New responsibilities are isolated in economics, contextstore, contextopt and evals packages. Prefer standard-library/local deterministic implementations; any dependency requires licensing, vulnerability and packaging review.

## Global contracts

- Exact model selections remain exact. `pea/auto` explicitly permits quality-qualified model selection. `pea/free` never silently bills; `pea/local` never silently leaves the machine.
- Use only approved provider accounts. Privacy restrictions precede price; no silent enrollment in anonymous endpoints or training-enabled routes.
- Unknown price, quota, capability or context length is unknown, not zero/unlimited/supported.
- Preserve tools, structured outputs, images, reasoning controls and nonportable continuation state. Never manufacture successful stream termination.
- Local assistance is opt-in; no automatic downloads, process startup, network scans or fallback-provider switches.
- Safe optimizations are automatic when eligible. Unsupported shapes pass through. Lossy optimizations require recoverability and release evidence before default promotion.
- All internal turns, retries and cache writes count toward the deadline, attempt/spend limits and observed costs. Report estimates separately from provider-published charges.
- No restart or reconfiguration of the proxy carrying the current agent session. Test isolated instances with temporary config/secrets and mock upstreams.

## Execution rules

Each task uses red → green → refactor: first implement the named assertions, run the focused command and record the expected failure; implement only that task; rerun focused and affected regression suites. New-file paths below are intentional deliverables, not existing files. Use isolated worktrees for implementation. Shared-file changes are serial; parallel-safe tasks may run independently only after their contracts land. Do not run live paid evaluations without a separately approved budget.

Remote issue disposition is proposed, not remotely applied. No push, issue closure or release tag is authorized by this local planning work. Archive this index and companion plan files under docs/archive/plans/ when shipped or dropped; repair their links together.
