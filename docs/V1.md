PeaProxy on `main` is already a shipped **1.6.x** local gateway (latest GitHub Release **v1.6.9**). A **1.0** tag is a honesty/quality cut, not a new OAuth program, not a tray app, and **not a second 1.6 release**.

## Already shippable (1.6.x)

Do not rebuild these for 1.0:

- Live catalog (`ListModels` source of truth; hide is listing-only; optional pin/rename)
- OpenAI `/v1/chat/completions` + Claude `/v1/messages` (true SSE, `finish_reason` before `[DONE]`) + Codex `/v1/responses`
- Vision-in Showcase (URL / upload), image-out Showcase (real `/v1/images/generations`, not fake chat), and embeddings Showcase (real `/v1/embeddings`, not fake chat)
- Official **API-key** adapters and hosted/local OpenAI-compat presets, including OpenCode Go (`opencode_go`)
- Subscription **OAuth** for Claude, Codex, Gemini/Antigravity, xAI, Kimi, Meta Muse, GitHub Copilot — **ToS/ban risk**; authors not liable; keys remain official
- `anthropic_oauth` Messages: Claude Code fingerprint + **system cloak** (billing header + CLI identity; caller system relocated, never deleted)
- `openai_oauth` Codex Responses: force `store: false`, omit `max_output_tokens` and `stream_options`
- OS keychain / encrypted-file secrets (no plaintext tokens in YAML)
- Round-robin / fill-first / sticky failover, retryable status + error-body skip, 30s cooldown, Health UI / `peaproxy health` with quota remaining
- Harness presets + `peaproxy clients verify [--chat]` (client-preset cloak defaults **off**; OAuth Messages cloak is adapter-side, not a Pi/Cursor injection)
- Loopback default; LAN bind requires `--allow-lan` + admin token
- CLI + localhost UI only (**no tray, by design**)
- CLI parity with Catalog / Health / Request log: `peaproxy catalog pin|rename|hide`, `requests tail`, `health`, plus `accounts add` presets
- Settings, first-run Accounts CTAs, `config validate`, opt-in request inspector, persisted usage
- Tagged GitHub Releases (linux/darwin/windows, amd64+arm64); macOS Developer ID + notarization; Homebrew cask `ks1686/tap`

Install: Homebrew `brew tap ks1686/tap && brew install --cask peaproxy`, or `go install github.com/ks1686/peaproxy/cmd/peaproxy@latest` (follows `main`; pin a tagged 1.6.x such as `@v1.6.9` if you do not want `@latest` to move). GitHub Releases remain an alternative.
